# 智能体仪表盘

智能体仪表盘会列出此分页器进程中的每个顶层会话——包括本地会话和派生会话——并按状态分组。你可以在一个屏幕中预览、回复、附加、固定、重命名、停止智能体，或调度新的智能体。这里不会列出子智能体；它们在父智能体下运行，而父智能体已能显示当前是否有任务正在进行。

它并不是智能体模态框（`/config-agents` / `/agents`——定义和角色）、会话选择器（`/resume` / `Ctrl+S`——磁盘上的历史对话），也不是工作流运行界面（`/workflows`）。

---

## 打开仪表盘

- **`grok dashboard`**——启动 TUI 并直接进入仪表盘。
- **`/dashboard`**（别名为 **`/agents-dashboard`**、**`/sessions`**）——从会话内部打开。
- **`Ctrl+\`**——打开与斜杠命令相同的视图。

在最小模式下会隐藏此功能。设置 `GROK_AGENT_DASHBOARD=0` 或 `[dashboard].enabled = false` 可将其禁用。

## 你会看到什么

```
 Grok Build · 仪表盘 — 4 个智能体 · 2 个等待中
▌● 审查者 · 审核词元流程          等待你的输入                 2m
 ● 实现者 · 修复登录缺陷          运行中：cargo test           12m
 ⋅ 重构 · feat/login              回复中…                     24m
 ○ 日常维护                       空闲                         1h
 ● 实现者 · 添加登录测试          8 个工具 · 1.2k 词元        14m
╭─────────────────────────────────────────────────────────────────╮
│ ❯ 调度新智能体                                                  │
╰─ 调度 ──────────────────────────────────────────────────────────╯
 ↑/↓ 选择（预览）· Enter 打开 · Ctrl+R 重命名 · Ctrl+T 固定 · Ctrl+X 停止 · ? 帮助 · Esc 新建
```

每一行都是一个顶层智能体。默认按状态排序（需要输入 → 工作中 → 空闲 → 未活动 → 已完成 → 失败），使相同状态的行彼此相邻；也可以按工作目录排序（使用 `Ctrl+G` 切换）。**未活动**表示仅存在于名册中、由其他分页器进程拥有且尚未被当前进程加载的会话——这些通常只是后台噪声，因此该分区**初始为折叠状态**（使用 `→` 或单击展开）。

为了让**空闲**分区易于浏览，只有最近的空闲智能体会保持可见——最新的 8 个，以及过去一小时内曾活跃的所有智能体。其余智能体会折叠到分组底部的**“还有 N 个”**行中；选中该行后按 `Enter` / `→`（或单击）可展开，按 `←` 可重新折叠。空闲分区的标题始终显示真实总数。启用筛选或搜索时不会进行折叠。

状态图标与 Grok Build 中其他会话列表保持一致：

- `⋅`/`:`/`⸬`/`⁙`——表示**工作中**的动画旋转图标
- `●`——表示**需要输入**、**已完成**、**失败**、**已阻塞**的实心圆（颜色依次为黄色 / 绿色 / 红色 / 琥珀色）
- `○`——表示**空闲**和**未活动**的空心圆

只要仍有实时后台工作，即使当前回合已经结束，相应行也会保持为**工作中**——例如后台任务、`monitor` 或活动的定时 `/loop`。活动行会说明仍在运行的内容（例如 `1 个监视器 · 2 个循环仍在运行`）。

界面中没有内联分组标题；排序顺序会让相同状态的行彼此相邻，而每行的圆点和颜色会表明所属分组。

调度输入框使用与智能体视图相同的提示输入框外观。按 `Ctrl+/` 可切换到**搜索模式**：`❯` 前缀会变成黄色的 `搜索：`，输入内容会实时筛选列表，而不是调度智能体。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| `↑` / `↓`、`j` / `k` | 在行和分区标题之间导航（选中一行会打开预览） |
| `→` / `←`（位于分区标题上） | 展开 / 折叠分区（Vim 模式下为 `l` / `h`） |
| `Enter`（位于分区标题上） | 在分区的折叠 / 展开状态之间切换 |
| `Enter`（回复为空） | 全屏打开所选智能体（详情视图） |
| `Ctrl+S` | 发送预览回复并打开智能体（或调度并附加新会话） |
| `Shift+Enter` / `Alt+Enter` | 在回复 / 调度输入框中插入换行 |
| `1`–`9` | 预览中显示选项时，回答待处理的权限请求 / 问题 |
| `Enter`（已输入回复） | 向所选智能体发送回复或将其加入队列 |
| `/` | 在提示中输入字面量 `/` |
| `Ctrl+/` | 切换搜索模式（实时筛选行） |
| `Ctrl+R` | 重命名所选行 |
| `Ctrl+T` | 固定 / 取消固定 |
| `Ctrl+G` | 切换分组方式（状态 ↔ 目录） |
| `Ctrl+X` | 取消正在运行的回合；或在 2 秒内按两次以永久删除会话 |
| 悬停 + 点击 `[✗]` | 永久删除空闲 / 已完成行（再点一次确认） |
| `Shift+↑` / `Shift+↓` | 调整已固定行的顺序 |
| `Esc` | 逐步返回：取消搜索 → 关闭预览 → 清除筛选 → 取消聚焦调度输入框 → 取消选择行 → 退出。绝不会清除已输入的调度草稿（请使用 `Ctrl+U` / `Ctrl+C` 清除） |
| `Ctrl+\` | 从详情视图返回，或退出仪表盘 |
| `Ctrl+.`（备选：`?`） | 打开快捷键速查表。当终端无法传递 `Ctrl+.` 时，页脚会显示 `?`。列表获得焦点或草稿为空时，直接按 `?` 可打开帮助 |

按状态分组时，每个分组都有一个**分区标题**（例如“工作中”“空闲”），并带有 `▸`/`▾` 标记。选中标题后按 `→` / `←` 可展开或折叠（Vim 模式下为 `l` / `h`）。单击可以切换状态；悬停时会高亮。仪表盘保持打开期间会记住折叠状态。每次分页器启动时，**未活动**分区初始均为折叠状态；将其展开后，状态会保持到退出为止。

打开一行会在**详情视图**中显示该智能体的对话：顶部标题栏（智能体名称；右侧为 `{i}/{n}` 循环切换标签和 `[仪表盘]`）位于全宽对话上方——没有带边框的模态框——因此内边距与列表视图一致。按键会发送给已附加的智能体；`Esc` / `Ctrl+\`（或 `[仪表盘]`）会返回仪表盘；`[‹]` / `[›]` 用于循环切换智能体。快捷键栏会显示 `Ctrl+\：返回仪表盘`。注意：`Esc` 只会返回；在智能体中使用 `/exit` 会关闭会话（仪表盘提示：“会话已关闭”）。

详情视图中 `Ctrl+X` 的行为取决于当前状态。**回合正在运行**时，它会取消回合（与 `Ctrl+C` 相同，包括是否保留子智能体的提示），绝不会关闭会话。其他情况下——智能体**空闲**、斜杠命令正在执行，或者取消操作仍待完成——`Ctrl+X` 会进入确认状态：在 2 秒内再次按下可关闭会话并返回仪表盘。按任意其他键都会取消确认；如果在确认窗口内启动了回合，确认按键会改为取消该回合。（如果你的终端也将 `Ctrl+X` 用作速查表快捷键，请在详情视图中使用 `Ctrl+.`。）

参阅[键盘快捷键](../03-keyboard-shortcuts.md#agent-dashboard)。

## 完成或关闭会话

这里**没有**“标记为已完成”命令。行状态由智能体的实际状态推导得出：

- 工作自行结束时（回合已完成，且没有仍在运行的后台任务 / `monitor` / `/loop`），状态为**已完成** / **失败**。
- 回合正在运行时，按**一次 `Ctrl+X`**会取消该回合。
- 于 2 秒内按**两次 `Ctrl+X`**会**永久删除**会话（与 `/delete` 相同）。将鼠标悬停在空闲 / 已完成行上时，年龄列会换成 `[✗]`，再点击两次可确认删除。
- 在详情视图中，`/exit` 也会关闭会话（Esc 只会返回）。在已附加的智能体中执行 `/delete` 会清除该会话并返回首页。

这里没有手动完成标志。若要离开会话但不删除历史，请使用 `/exit`。

## 调度输入框

底部文本输入区**始终会创建新会话**。所选行只是导航光标，并不是回复目标——要与智能体对话，请将其打开。

- 自由文本 → 使用该提示创建新的顶层会话。文本绝不会被当作筛选条件（即使以 `/`、`s:`、`a:` 或 `#` 开头）；筛选必须使用 `Ctrl+/` 搜索模式。开头的 `/` 会运行分页器全局斜杠命令。
- 空输入 → 打开所选行；如果焦点位于 `[+ 新智能体]`，则创建新智能体。

输入内容后按 `Ctrl+S` 会执行调度**并**附加会话；直接按 `Enter` 则会留在仪表盘中，方便连续调度多个会话。`Shift+Enter` / `Alt+Enter` 用于插入换行；输入框会随草稿增高（达到上限后改为滚动）。

空提示或仅包含空白字符的提示会被忽略。超过 64 KiB 的提示会被拒绝，并显示提示消息。

### 焦点：输入栏 ↔ 概览列表（`Tab`）

界面有两个焦点区域：**调度输入框**和**概览列表**。`Tab` 可在两者之间切换；未激活的输入框会将边框变暗并隐藏光标。

打开仪表盘时，如果至少存在一个智能体，焦点默认位于**概览列表**（因此 `↑`/`↓` / Vim 的 `j`/`k` 可立即用于导航）。如果**没有**智能体，焦点会留在**调度输入框**。无论哪种情况，光标起初都位于 `[+ 新智能体]`（不会预先选择任何智能体行）。

- **输入框获得焦点**：输入新会话的提示。提示为空时，`↑`/`↓` 用于导航行；提示非空时，用于移动文本光标。`Esc` 会取消输入框焦点并返回列表（保留草稿）。
- **概览列表获得焦点**：`↑`/`↓`（以及 Vim 的 `j`/`k`）用于在行之间移动。`Enter` 会打开高亮显示的智能体（在 `[+ 新智能体]` 上时，则发送已输入的草稿或创建新会话）。`Esc` 会留在列表中并逐步返回——先清除筛选，再取消选择（→ `[+ 新智能体]`），然后退出。`Tab`、`i`（Vim）或任何可打印字符都会将焦点返回输入框。

## 预览面板

选中智能体行时，**预览面板**会取代调度输入框。未选择行时（位于 `[+ 新智能体]`，或按下 `Esc` 后），调度输入框会重新出现。选中一行可与现有智能体对话；取消选择则可启动新智能体。

面板从上到下依次显示：标题（**最近回复类型**——“思考中” / “思考” / “回复” / “编辑” / “读取” / `Bash` / ……——以及**时间**）、最近一次回复（自动换行，最多约 3 行；截断时显示 `…`），以及实时的 `❯ 回复` 输入框。

所选智能体的**模型**会显示在面板底部边框上；在始终批准（yolo）模式下，还会显示 **`always-approve`** 标志（与调度输入框的徽章位置相同），回答问题时也会显示。列表行不再重复显示模型或始终批准徽章。

**`Shift+Tab` 会循环切换预览中智能体的模式**（普通 → 计划 → 始终批准 → 普通），并立即应用到**实时运行的**智能体。在调度输入框上，Shift+Tab 只会为*下一个*智能体预设模式。

调度输入框只会创建新会话，而预览回复则会**与所选智能体对话**：

- **在 `❯ 回复` 中输入内容，然后按 `Enter`**即可发送。空闲智能体会立即开始处理；繁忙智能体会将消息**加入队列**（与智能体视图的提示输入框相同）。`Ctrl+S` 会回复并打开详情视图；`Shift+Enter` / `Alt+Enter` 用于插入换行（输入框会随回复草稿增高）。
- 回复为空时按 `Enter` 会打开智能体。
- 回复已有内容时，**`↑`/`↓` 用于移动文本光标**。回复为空（或通过 `Tab` 取消焦点）时，`↑`/`↓` 会**切换所选智能体**——面板会随之切换，输入到一半的草稿会被清除，以免误发给其他智能体。（回复中已有草稿时，请按 `Tab` 切换到列表后再导航。）
- **`Esc` 会取消选择**：先清除已输入的回复，然后取消选择并聚焦 `[+ 新智能体]`。
- **`Tab`**在回复输入框和行列表之间切换焦点；输入可打印字符会重新聚焦回复输入框。
- 支持完整的提示编辑器（与调度输入框 / 智能体提示输入框相同）：多行粘贴折叠块、鼠标选择、按词导航、`Ctrl+A`/`Ctrl+E`、`Alt+Backspace`、`Ctrl+W`/`Ctrl+U`/`Ctrl+K`、撤销、Shift+方向键选择、`Ctrl+Shift+V` 内联粘贴。**`@`**会打开文件选择器，其根目录为**预览中智能体的**工作目录；下拉菜单浮动显示在面板上方。面板打开时，仪表盘组合键（`Ctrl+X` 停止、`Ctrl+T` 固定、`Shift+↑/↓` 调整顺序等）仍然优先。
- 存在待处理的**权限 / ask-tool** 问题时，`❯ 回复` 会隐藏，改为显示选项列表。使用 **`↑`/`↓` 高亮选项**、**`Enter` 回答**，或按 **`1`–`9`** 直接回答。自由文本形式的**否 / 拒绝**选项和 ask-tool 的**其他**选项可在自由文本行中接受输入。包含多个问题的 Ask 表单会逐个显示（`(i/N)`）；多选表单需要在智能体自身的视图中处理。

在高度很小的终端中，面板可能无法容纳；此时即使选中了行，也会继续显示调度输入框。

## 搜索 / 筛选（`Ctrl+/`）

`Ctrl+/` 用于切换搜索模式，从而确保普通输入始终用于调度。前缀会从 `❯` 变为黄色的 `搜索：`；每次按键都会实时筛选列表。

- `Enter`——确认：保留筛选条件并返回调度输入框。
- `Esc` 或 `Ctrl+/`——取消：清除筛选条件并退出搜索。
- `↑` / `↓`——在筛选后的行中导航。

前缀（仅在搜索模式中生效）：

- `a:<name>`——智能体标签（不区分大小写的子字符串；角色 / 职能）。
- `s:<state>`——行状态：`working`、`idle`、`completed`、`failed`、`needs-input`、`blocked`，以及同义词（`busy`/`running`/`done` 等）。
- `#<text>`——匹配 `#<text>` 的子字符串（标签中的字面量 `#`）。
- 其他内容——在标签和工作目录中进行子字符串匹配。

## 持久化

每位用户的偏好设置位于 `~/.grok/config.toml` 的 `[dashboard]` 下：

```toml
[dashboard]
enabled = true
grouping = "state"   # 或 "directory"
pinned   = ["top:<session_id>", "sub:<parent_session_id>:<child_session_id>"]
reorder  = ["top:<session_id>"]
```

固定 / 排序条目使用**会话 ID**（而不是每个进程中的智能体槽位），因此重启后仍会保留。
